- GET /projects -> {projects:[{id,name,revision,activeRunId,updatedAt,isDefault}],defaultProjectId:null|string}.
- POST /projects {name} -> {project:metadata}; POST /projects/:projectId/rename {name} -> {project:metadata}.
- Existing /workspace routes stay for default compatibility. Add /projects/:projectId/workspace for GET status, /file?path and /download (no create alias). Status includes workspace.id and existing shape.
- Existing /workspace/deliverables routes remain; identical /projects/:projectId/workspace/deliverables routes for metadata, POST preview {entry,revision}, GET download?entry&revision.
- GET /projects/:projectId/versions -> {versions:[{id,label,kind,sourceRevision,createdAt,fileCount,bytes}]}.
- POST /projects/:projectId/versions {label,revision} -> {version:metadata}.
- POST /projects/:projectId/versions/:versionId/restore {revision} -> {restoredVersionId,revision,backupVersionId}.
- /projects/:projectId/versions/:versionId/deliverables mirrors deliverable metadata/preview/download, reads immutable historical snapshot, does not require current project idle. Returned snapshot revision is sourceRevision. Include projectId and versionId in returned metadata/preview where useful, preserving legacy fields.
- GET /departments/dev/conversation?projectId=uuid and POST /departments/dev/chat {projectId, text, revision, execute?,image?}; response includes projectId (null when no project). Reject projectId on other departments. Keep existing heartbeat route.
