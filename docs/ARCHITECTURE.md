## 数据流与边界

浏览器只持 HttpOnly 会话 cookie 和 CSRF 标识。Cognito 授权码在服务器交换并校验；Redis 保存一小时会话。每个租户 API 都先核对成员关系，再设置 PostgreSQL 事务内的租户/用户上下文。关键表启用 FORCE RLS，应用数据库账号不是超级用户且不能绕过 RLS。权限变更每次重新查询，不依赖助手缓存。

用户与企业通过 memberships 多对多关联。企业有 owner/admin/member 角色；个人版禁止邀请额外成员。对话绑定 tenant_id/user_id/agent_id。服务器生成运行会话 UUID，不接受客户端传入其他人的运行标识。

共享 Harness 分为启用记忆与无记忆两个配置。每次调用从数据库读取 profile；actorId 为企业+用户+助手的哈希。模型只可选择管理员白名单，第一版没有开放任意工具、代码执行或外部网络工具。账号删除、企业数据导出/删除和记忆清理工作流仍需后续实现，不能承诺已具备完整数据治理后台。

## 计量

请求 UUID 在租户+用户范围唯一；成功响应重放不重复调用模型。失败后不自动重试收费调用，未知状态需要核对。Token 数来自服务端响应；价格来自运营配置并保存快照，没设置价格时显示“待配置价格”。该账本不是云厂商发票，也不覆盖运行时、记忆、网络等 AWS 成本。

进程在调用中途退出可能留下 pending 记录；上线收费前需增加后台核对任务、供应商账单对账、额度/预算、订阅及退款/支付通知幂等逻辑。目前没有实际扣款，支付宝与微信按后续范围接入。

## 安全与运行

云端业务只接受经 CloudFront 的流量，ALB 限来源并校验随机源站密钥；API 响应禁止 CDN 缓存，静态资源可缓存。RDS、Redis 位于私有子网，云端传输使用 TLS。业务任务不注入数据库管理员密码；迁移任务单独执行。Terraform state 包含敏感值，使用加密、版本化、私有 S3 后端及锁，且不提交 Git。

香港到美国的助手调用意味着提示词与记忆会进入美国区域，需在正式用户隐私说明中明确。用户已选择该跨区域部署。当前没有真实云端数据传输。

## 企业技能上传安装（2026-10-11）

在现有技能库上扩展，右侧上传入口支持单个Markdown技能或包含一份SKILL.md的ZIP，类型分为单项技能/流程技能包。中间通过「技能目录 / 我的技能」切换；原600项目录仍未安装，原预览上传/来源安装入口已移除。小于900px时上传入口移到内容区域，避免被隐藏的右栏挡住功能。所有控件和错误提供中英文，用户上传的说明保持原文。

链路：选择文件 → POST /api/tenants/:tenantId/skills/uploads → 登录/CSRF/所有者或管理员权限 → 限量ZIP与YAML校验 → 数据库事务保存技能包原字节、元信息、安装记录和审计 → 返回「我的技能」。GET /skills/installed仅返回当前企业元信息，不返回原始包。

`apps/api/src/skill-upload.mjs`负责校验和保存；`database/migrations/002_installed_skills.sql`新增installed_skills表，不修改旧数据。完整上传包以bytea私有保存，与安装元信息在同一事务提交，重启和多实例不会丢失文件；RLS和显式tenant_id双重隔离。当前面向小技能包，单包6 MiB、展开30 MiB、200个条目、SKILL.md 512 KiB，每企业100项/原包100 MiB。未来大文件改用对象存储时需迁移package_data，目录稳定ID可保留。

同名安装拒绝覆盖；租户行锁保证并发配额检查一致。ZIP检查绝对路径/上级路径/重复路径/符号链接/加密/CRC和解压大小；YAML禁用别名展开并限制大小。只在内存检查，没有解压到全局目录、自动运行脚本或安装依赖。

此阶段「installed」表示程序已持久保存并登记上传包；runtimeReady始终false，UI显示待接入智能体调用。智能体绑定、执行、依赖安装、启停、卸载、版本更新仍待实现。

- 当前拆分是明确标注的本地关键词规则，不是LLM：草稿→用户修改→确认分工→待执行。日期默认当天，可编辑；完整指令保存在每项任务里。任务标题/系统回复有中英文，用户内容保留原文。长期对话保留尚未确认草稿对应消息，防止草稿入口被截断。
- 「体验示例」仅存在当前页面内存，与数据库真实统计分离，退出即丢弃；用于预览待发布许可、报告详情、退回反馈、归档状态。审批状态只能从等待许可进入已许可/待修改，不存在直接published转换，也不调用发布渠道。正式页在没有成果时展示空状态。
- 当前没有LLM自由对话、自动部门执行、定时催办、语音输入、真实视频/报告交付或社交平台发布。催办/汇报快捷入口真实记录请求，但回复明确说明执行/通知尚未连接。部署继续沿用现有Terraform和镜像构建，未创建云资源。
