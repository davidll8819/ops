# 成果、资料室与部门模型能力（2026-10-11）

## 产品入口与数据流

私人秘书接收文字／图片／文本附件 → 模型整理任务及前置关系 → 用户确认派发 → 后台队列按依赖执行并交接成果 → 任务成果页展示完整交付 → 资料室保存归档。

- 左侧“任务成果”默认展示已完成任务，也可切换全部／待处理。办公室统计卡片和右侧进度进入同一个独立详情页。
- 私人秘书保留形象、今日新闻和对话。任务执行记录及发布确认移至任务详情；对话中的分工确认仍然保留。
- 资料室复用 workspace_files，并关联 secretary_workspaces.board.tasks；无需新增数据库或迁移旧文件。进入资料室时幂等补齐历史完成任务的归档。
- 图片保存在当前应用的私有文件存储。运营服务返回的媒体链接保存在任务及归档文档中，视频可内嵌播放；视频原文件仍由运营服务对象存储管理，链接有效期依赖原服务。
- 文件和任务仍按企业＋用户隔离，不因新增资料室而变成企业所有成员共享。

## 部门任务接续（2026-10-12）

- 确认派发后任务写入持久队列，网页关闭不停止已派发工作。前置任务未完成时后续部门等待；全部完成后自动领取，不再由浏览器逐项执行。
- 后续部门接收数据库中的实际文案、分镜、来源与已保存图片，保留 `receivedInputs` 交接记录。设计可生成文字方案或图片；运营服务就绪后自动接收前序成果并开始制作。任务详情、秘书分工卡和任务进度显示前置状态及“已收到成果”，详情提供成果下载。
- 完成后保存真实结果并归档；失败显示阻塞原因。运营状态以原运行服务任务记录为准，已有运行编号或提交结果未知时不重复启动。制作自动接续不改变对外发布审批要求。

## 模型设置

公司模型分为 strong、fast、cheap 三个文字档位，以及 image、video、search 三项专用能力。

部门的 capabilities.image/video/search 分别有 enabled 开关和可选 model；model 为空时继承公司能力模型。文字保留 tier 和 fallback。

默认能力：秘书搜索；运营图片＋视频；设计图片；市场调研／拓客搜索；其他部门默认关闭专用能力。能力配置表示可用模型路由，不能替代具体执行工具。

本地企业搜索选择 gemini-3.5-flash。模型列表中的 searchVerified 对应本次验证过请求格式的 Gemini 3.5 Flash、Gemini 2.5 Pro、Grok 4.3，不保证其他账号权限或长期可用性。搜索走现有企业 AI 密钥，不增加独立搜索密钥。

## 附件与新闻边界

附件支持 PNG/JPG/WebP（每张2 MB）、TXT/MD/CSV/JSON（每份256 KB及24,000字符），每条最多4个。模型是否能理解图片仍取决于所选文字模型的视觉能力，失败时返回实际错误。

新闻按当前企业和用户保存。同一上海日期、主题和语言复用已生成内容；其他主题或语言会重新调用企业模型。展示实际来源和检索时间，旧报道必须标日期，不伪装为当天发生。生成失败保留上一份简报。

运营服务当前没有本机企业运行绑定，尚未完成真实视频生成与平台发布联调。不得把运营链接解析单元测试等同于整条视频生产链路验收。
